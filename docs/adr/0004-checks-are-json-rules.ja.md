# 0004. 検査はscriptでなくJSONの決まりで書く

## 決めたこと

出す側のスキルが、`musubi check`が使う側に回す検査をどの形で書くか。

## 選んだ案

検査は、要る見出しとその順、残してはいけない文字 (`Fill in:`など)、表の要る列のような決まりをJSONで書いた物にする。
`musubi check`はその決まりを読み、使う側がそれぞれ名指した例に回す。
出す側のcodeは使う側の手元で走らないので、悪い検査が紛れても何も実行されない。
検査に書ける決まりの種類は定義が決め、足りない時は定義に足す。

## 却下した案

| 案 | 採らなかった理由 |
|---|---|
| `musubi check`が出す側のscriptを回す | 出す側のcodeが使う側の手元で走る |
| JSONの決まりを既定にし、使う人が許した時だけscriptも回す | 出す側のcodeを走らせる経路が残る |
| LLMに判定させる | 回すたびに結果が変わり、回すたびに費用が掛かる |
