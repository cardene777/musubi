# 0008. `musubi install`はスキルが準拠するスキルを利用者が名指したインストール元からインストールする

## 決めること

スキルが`musubi.json`で準拠するproviderを、どのエージェントでもそのスキルと一緒にインストールする方法。

## 採った案

`musubi install <スキル名>... --from <インストール元>...`は、名指したスキルと、その`musubi.json`の準拠ごとのproviderを、準拠の連なりの最後までインストールする。
必須の準拠のproviderは必ずインストールし、任意の準拠のproviderは、利用者が`--with`で名指した時か、`--lang`で渡した言語が準拠の`when`に合う時だけインストールする (判断の記録[0009](0009-optional-follows-name-their-languages.ja.md))。
インストール元は利用者が`--from`で名指すフォルダかgitのリポジトリで、コマンドはその中からフォルダ名でスキルを探す。
`musubi.json`は今どおりスキルとコンテンツとバージョンだけを書くので、スキルのインストール元はコマンドの引数かインストーラーにだけ書く。
定義には、インストーラーがどのproviderをインストールするかを書いた節を足し、どのインストーラーも同じ`musubi.json`から同じproviderを選べるようにする。

## 却下した案

| 案 | 採らない理由 |
|---|---|
| インストーラーが読む形だけを定義に足し、musubiはインストールしない | その形を読むインストーラーがまだ無いので、インストーラーが対応するまで誰もproviderをインストールできない |
| Claude Codeのプラグインの`dependencies`に任せたままにする | そのフィールドを持たないエージェントでは、今もproviderがインストールされない |
| 準拠ごとにインストール元のフィールドを足す | インストール元を`musubi.json`とインストーラーの2か所に書くことになる |
| サイトでスキル名からインストール元を引く | スキル名を持つ中央の一覧を置くことになり、判断の記録[0005](0005-registry-lists-skill-folders.ja.md)が却下した形になる |
| `--to`を毎回必須にする | スキルのフォルダが1つしか無い利用者も、毎回同じフォルダを打つことになる |
| 常に`.claude/skills`へインストールする | ほかのエージェントだけが読むフォルダへスキルをインストールできない |
