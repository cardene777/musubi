# 0003. 版の範囲と指紋を並べて書き、lockfileを持たない

## 決めたこと

使う側のスキルが従う中身をどう固定し、その中身が書き換えられた時にどう気付くか。

## 選んだ案

使う側は、従える版のsemverの範囲と、最後に確かめた中身の指紋を、同じ`musubi.json`に並べて書く。
指紋は、中身のfileと検査と、エージェントが読む時に通る出す側の`SKILL.md`から作る。
`musubi check`は入れた後と更新の後に指紋を照らし、合わない時は使う側を名指して止め、確かめ直して通った時だけ指紋を書き換える。
使う側の本文にも、musubiの命令が在れば読む前に指紋を照らす1行を置く。

## 却下した案

| 案 | 採らなかった理由 |
|---|---|
| 範囲を`musubi.json`に、確かめた版と指紋を`musubi.lock`に分ける | 使う側が見る所が2か所になる |
| 指紋だけで固定する | 指紋を書き換えるまで直しを受け取れない |
| 範囲だけを書く | 範囲の中で書き換えられても気付けない |
| 確かめる時だけ指紋を照らす | 入れる道具が自分でスキルを更新すると、確かめた後に中身が変わる |
| 中身に署名する | 出す側がそれぞれ鍵を管理することになる |
