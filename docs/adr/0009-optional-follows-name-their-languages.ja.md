# 0009. 任意の準拠はproviderをインストールする言語を`when`に書く

## 決めること

利用者が日本語で書く時のように、利用者が名指さなくても任意の準拠のproviderをインストールする条件を、consumerがどう書くか。

## 採った案

定義のバージョン`2026-11-21`で`follows.<参照>.when`を加え、`optional: true`と一緒の時だけ書けるようにする。
`when`が持つフィールドは`languages`の1つで、`ja`のような言語タグを並べる。
`musubi install --lang <言語タグ>`は、`languages`に主な言語が同じタグを持つ任意の準拠ごとに、そのproviderをインストールする。
たとえば`--lang ja-JP`は`ja`に合う。
`musubi add <参照> --optional --lang <言語タグ>`は`when`を書き、`musubi add`は書くフィールドを知っている最も古い定義のバージョンへ`musubi`を上げる。
`2026-11-20`を書いた`musubi.json`は今も通り、その中の`when`は知らないフィールドとして拒否する。

## 却下した案

| 案 | 採らない理由 |
|---|---|
| 条件を自由な文で書き、エージェントが読んで決める | コマンドが条件を判定できず、インストーラーごとにインストールするスキルが変わる |
| 言語を`LANG`から読む | 端末の言語の設定と利用者が書く言語は違うことがあり、同じコマンドでも端末ごとにインストールするスキルが変わる |
| 条件を持たず、`--with`だけで選ぶ | Issueは、条件に合う時に任意の準拠のproviderをインストールすることを求めている |
| 日付を上げずに`2026-11-20`へ`when`を足す | npmのmusubi-cli 0.2.0は`2026-11-20`を読み、`when`を知らないフィールドとして拒否し、新しい定義が要ることが伝わらない |
| `musubi add`は今どおり`musubi`を最新の定義のバージョンへ上げる | `2026-11-20`で書ける準拠にも、musubi-cli 0.2.0が拒否する`2026-11-21`を`musubi add --optional`が書く |
