A proposal for Agent Skills

Bind what one skill provides to the skills that follow it

A skill offers content under a name and a version, such as a document format or a check. Another skill declares that it follows that content. When the content changes, every skill that follows it is checked again.

$npm install -g musubi-cli

How it works

Two declarations and one check

  1. 01

    Provide content

    The provider names its content in musubi.json and gives it a version.

    design-doc/musubi.json
    "provides": {
  "design": {
    "version": "1.0.0",
    "file": "formats/design.md",
    "check": "checks/design.json"
  }
}
  2. 02

    Follow it

    A follower names that content, the versions it accepts, and the fingerprint it was checked against.

    api-design/musubi.json
    "follows": {
  "design-doc/design": {
    "version": "^1.0.0",
    "integrity": "sha256-yNSw…",
    "examples": [
      "examples/orders-api.md"
    ]
  }
}
  3. 03

    Check again

    When the content changes, musubi check names each follower whose fingerprint no longer matches. After a review, --update records the new one.

    terminal
    $ musubi check skills
skills/api-design/musubi.json:7: api-design: the fingerprint of design-doc/design does not match, so its content changed after the last check; review the change and run musubi check --update
musubi check: 1 problem
$ musubi check skills --update
musubi check: ok (skills=2, follows=1, updated=1)
