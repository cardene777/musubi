Agent Skillsへの提案

スキルが提供するコンテンツとそれに準拠するスキルを結ぶ

スキルは、文書の書式やチェックのようなコンテンツに、名前とバージョンを付けて提供します。別のスキルは、そのコンテンツに準拠すると宣言します。コンテンツが変わると、準拠する全てのスキルが再チェックされます。

$npm install -g musubi-cli
定義を読むスキルを見る

仕組み

2つの宣言と1つのチェック

  1. 01

    コンテンツを提供する

    providerのスキルは、musubi.jsonでコンテンツに名前とバージョンを付けます。

    design-doc/musubi.json
    "provides": {
  "design": {
    "version": "1.0.0",
    "file": "formats/design.md",
    "check": "checks/design.json"
  }
}
  2. 02

    コンテンツに準拠する

    consumerのスキルは、準拠するコンテンツと、受け入れるバージョンの範囲と、チェックした時のフィンガープリントを書きます。

    api-design/musubi.json
    "follows": {
  "design-doc/design": {
    "version": "^1.0.0",
    "integrity": "sha256-yNSw…",
    "examples": [
      "examples/orders-api.md"
    ]
  }
}
  3. 03

    再チェックする

    コンテンツが変わると、musubi checkはフィンガープリントが合わなくなったconsumerを挙げます。変更を確認した後に、--updateで新しいフィンガープリントを記録します。

    ターミナル
    $ musubi check skills
skills/api-design/musubi.json:7: api-design: the fingerprint of design-doc/design does not match, so its content changed after the last check; review the change and run musubi check --update
musubi check: 1 problem
$ musubi check skills --update
musubi check: ok (skills=2, follows=1, updated=1)

定義

providerとconsumerの宣言、見つけ方と読み込み方、バージョンとフィンガープリント、再チェック、チェックのルールを定めています。定義のバージョンは2026-11-19です。
